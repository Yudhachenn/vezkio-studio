GOOD TO KNOW

Frequently asked questions.

Apakah VEZKIO harus online?

Editor desktop dirancang offline-first. Beberapa fitur sistem seperti mengunduh installer atau memperbarui dependensi selama build membutuhkan internet.

Apakah ini sudah stabil seperti Canva atau Figma?

Belum. VEZKIO masih dalam tahap release candidate. Hasil rendering, file besar, dan performa harus terus diuji sebelum dinyatakan stabil.

Apakah proyek desain saya diunggah ke cloud?

Versi ini memakai penyimpanan proyek lokal/IndexedDB. Tidak ada sinkronisasi cloud bawaan; selalu simpan backup file .vezkio.

Mengapa tombol Download belum aktif?

Tombol akan aktif secara otomatis ketika ada GitHub Release publik yang memiliki file installer Windows. Draft release belum dianggap tersedia untuk pengguna.
